# Cursores Spa Kira

Pack inicial de cursores para la web de Spa Kira.

## Archivos
- kira-normal.png
- kira-pointer.png
- kira-link.png
- kira-click.png
- kira-move.png
- kira-text.png
- kira-loading.png
- kira-not-allowed.png
- kira-pet.png
- kira-calendar.png
- kira-save.png
- kira-delete.png
- spa-kira-cursors.css

## Uso
Copia la carpeta `cursors` a tu proyecto y coloca allí los PNG.
Luego importa el CSS:

```html
<link rel="stylesheet" href="/css/spa-kira-cursors.css">
```

Los PNG están preparados a 48x48 px, un tamaño práctico para cursores web.
Para mayor compatibilidad se deja siempre un cursor CSS estándar como respaldo.
